# Como subir pelo celular

1. Crie um repositório público chamado exatamente `OTTHI-WORLD-EDU`.
2. Extraia o ZIP completo.
3. Use **Add file → Upload files**.
4. Envie todos os arquivos e pastas preservando a estrutura.
5. Confirme o commit na branch `main`.
6. Abra **Settings → Pages**.
7. Escolha **Deploy from a branch**.
8. Selecione `main` e `/root`.
9. O endereço será `https://tsvalencio-ia.github.io/OTTHI-WORLD-EDU/`.
10. Publique as regras Firebase descritas em `docs/CONFIGURAR-FIREBASE.md`.

Não envie somente o ZIP fechado ao GitHub Pages. Os arquivos precisam estar extraídos na raiz.
